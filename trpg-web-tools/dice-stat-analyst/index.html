対応例：CCB<=80、CC<=60、RESB(10-16)、1d100<=55、s1d100、D100、判定結果の「出目 03 / 100 / ＞ 96」など。
キャラクター名は「名前：CC」「名前：CCB」「[main] 名前：CC」「[main] 名前：CCB」形式などから自動検出します。検出されたキャラクターはチェックを外すことで非表示にできます。
タブ除外ONの場合、[main] / [メイン] / [HO系] は解析対象、[雑談] / [other] / [info] / [おはらい] / [お祓い] / [運試し] は除外対象になります。
